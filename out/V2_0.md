# v2.0 — İSTENEN MİMARİ: AĞ HAZNEDE, BONCUKLAR AĞIZDA

> **Ağ haznenin içinde olmalı, boncuklar kapsülün ağzında olmalı, kapsül
> namlu ağzına çarptığı anda boncuklar fırlamalı, arkasından ağı çekmeli.**

Bu kuruldu. Bedeli: **namlu Ø43.4 → Ø55.0.**

---

## 1. NEDEN NAMLU BÜYÜMEK ZORUNDAYDI

6 boncuk yuvası ağız çevresinde **74.4 mm** yer istiyor (Ø9.6 bore +
2 × 1.4 mm cidar). Bu sayı küçültülemez — boncuk Ø8.80.

Yuvalar 40° eğimli olduğu için ağız düzleminde **elips** kesit verirler;
radyal yarı-eksenleri 6.2 değil **8.09 mm**. Ortada ağa kalan alan
`π·(R_pitch − 8.09)²`, ve R_pitch kapsül cidarıyla sınırlı.

| Namlu içi | R_pitch sınırı | Ağ geçişi | Hazne doluluğu |
|---|---|---|---|
| Ø43.4 | 13.4 | **Ø10.8 (97 mm²)** | %51 — ağ zor giriyor |
| **Ø55.0** | **18.2** | **Ø18.6 (271 mm²)** | **%31 — rahat** |

Ø43.4'te 97 mm² mutlak tavandı. İstenen mimari o çapta kurulamıyordu.

## 2. YUVALAR GENİŞLETİLDİ

Baskıda boncuklar zar zor giriyordu — haklı şikâyet:

| | eski | **yeni** |
|---|---|---|
| Yuva çapı | Ø9.2 | **Ø9.6** |
| Boncuk boşluğu | 0.4 mm | **0.8 mm** |
| Tutma dudağı | Ø8.40 | **Ø8.60** |
| Dudak sıkması | 0.4 mm | **0.2 mm** |
| Yuva derinliği | 7.0 mm | **7.5 mm** |

Dudak hâlâ boncuğu tutuyor (Ø8.60 < Ø8.80) ama elle bastırınca giriyor.

## 3. ÇALIŞMA SIRASI

1. Kapsül namlu ağzındaki omza çarpar ve **durur**
2. Boncuklar ataletle devam eder, 40°'lik yuvalardan **dışa doğru fırlar**
3. Boncukların önünde **hiçbir şey yoktur**
4. Ağ, köşelerinden **çekilerek** Ø18.6 geçişten hazneden çıkar

Gerçek ağ tabancalarının düzeni budur: **ağırlık önde, ağ arkada.**

## 4. DOĞRULAMA

`cad/kontrol_omuz.py`, `kontrol_ankraj.py` ve ağız düzlemi taraması:

| | |
|---|---|
| Merkezi bağlı boş alan | **271 mm² (Ø18.6)** — 161×161 ızgara taraması |
| Hazne hacmi | 35.9 cm³ · ağ ipi 11.1 cm³ → **%31** |
| Durdurma omzu | **300 mm² → 14.989 N** |
| Boncuk/koni payı | omuzda +2.68 mm, ağızda +1.00 mm |
| Anti-çakışma | arka boncuk ekseni 15.37 mm (≥9 gerekli) |
| Bant ankrajı payı | +4.28 mm |

### Yolda yakalanan hata
İlk denemede merkezi geçişin duvarını boru dış yüzeyine **tam teğet**
yapmıştım (ikisi de R10.11). Sıfır kalınlıkta temas booleanı bozdu: katı
`gecerli=False` çıktı ve ağız kesiti 0 mm² ölçüldü. `t_ara = 0.8 mm`
gerçek cidar eklendi.
